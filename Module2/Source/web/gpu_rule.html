Pixel tepat di tepi: siapa pemiliknya menurut GPU?

Raw WebGL2, tanpa antialiasing, vertex di sudut pixel integer (y ke bawah). Kiri: segitiga E4 A(1,1) B(6,2) C(3,7). Kanan: persegi 6x6 dari dua segitiga, oranye (2,2) (8,2) (8,8) dan biru (2,2) (8,8) (2,8). Dibandingkan dengan triangle(..., { fillRule: "gpu" }) di raster.mjs.
